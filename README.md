# SESCINC ARFF - simulador de estudo de caso

Protótipo web (arquivo único HTML/JS, Canvas 2D) para treinamento de bombeiros de aeródromo, base SESCINC (Navegantes/SBNF), com base no RBAC 153.

Abra index.html com navegantes-satelite.png na mesma pasta.

Os valores de categoria, tempos e autonomias são ilustrativos e devem ser validados com o RBAC 153.
